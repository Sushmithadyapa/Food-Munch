# Food Munch 🍴

A simple responsive food website built with HTML and CSS, using Bootstrap 4 for responsive layout and navigation.

## Features

- Responsive navigation bar
- Hero/banner section
- Why Choose Us section
- Explore Menu section
- Healthy food section
- Delivery and Payment section
- Thank-you/customer section
- Responsive Bootstrap grid
- Google Fonts
- Food images served through the original image URLs

## Technologies Used

- HTML5
- CSS3
- Bootstrap 4.5.2
- Google Fonts

## Project Structure

```text
food-munch/
├── index.html
├── style.css
└── README.md
```

## Run Locally

No installation or build command is required.

1. Download/clone this repository.
2. Open `index.html` in a browser.
3. Make sure you have an internet connection because Bootstrap, Google Fonts, JavaScript libraries, and the image assets are loaded from external CDNs.

## Notes

This is a static frontend project. It does not contain a backend, database, authentication, or real food-ordering functionality.

The navigation links and buttons are currently presentation elements based on the supplied source code.
